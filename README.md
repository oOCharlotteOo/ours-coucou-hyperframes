# Ours coucou — HyperFrames

Petite scène verticale de 5 secondes : un ours brun animé fait coucou avec la patte, sur un fond pastel.

## Composition

- Format : 1080 × 1920 (vertical)
- Durée cible : 5 secondes
- Fréquence : 30 images/seconde
- Scène : HTML/CSS autonome, avec animations CSS

## Lancer le projet

Prérequis : Node.js et FFmpeg installés.

```bash
npm install
npm run preview
```

Pour tenter le rendu vidéo :

```bash
npm run render
```

Le rendu MP4 n'est pas inclus dans ce dépôt : il reste à générer et à vérifier localement avec la version installée de HyperFrames.

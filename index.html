Une petite aventure numérique

De « Coucou toi ! »
à une vraie vidéo 🧸

👋🐻

Retour sur ce que nous avons construit ensemble.

Étape 1 · L'idée
💡

Un ours qui dit bonjour

Nous sommes partis d'une idée toute simple : créer un petit personnage chaleureux, animé, au format vertical.

Étape 2 · La création
🎨🐻

Donner vie à l'ours

Nous avons construit la scène en HTML et CSS : couleurs douces, visage, oreilles, petits pieds et bras qui salue.

Le résultat : « Coucou toi ! »
Étape 3 · Le projet
🧩

Organiser les fichiers

Nous avons préparé le projet HyperFrames, ses métadonnées, ses dépendances et les instructions pour générer la vidéo.

1080 × 1920 · 30 images par seconde
Étape 4 · L'automatisation
⚙️

GitHub Actions au travail

À chaque mise à jour, GitHub peut installer les outils, lancer le rendu, vérifier le fichier MP4 et préparer sa publication.

Une chaîne de fabrication reproductible.
Étape 5 · Le contrôle
🎬

Fabriquer et vérifier

Le rendu vidéo a bien été généré lors d'une exécution du workflow. Nous avons aussi prévu un contrôle du fichier avec FFmpeg.

Le premier obstacle concernait la configuration de GitHub Pages, pas le rendu.
Étape 6 · La publication
🌐🚀

Mettre la vidéo en ligne

Nous avons ajouté une page web avec un lecteur vidéo et un lien de téléchargement, puis configuré le déploiement via GitHub Pages.

Le déploiement final dépend de la réussite de l'exécution Actions.
Et maintenant ?
💗🐻

Une idée, un projet,
une réalisation !

Nous avons appris à créer, structurer, automatiser et préparer la mise en ligne d'une vidéo.

Merci pour cette belle collaboration. À la prochaine aventure !
